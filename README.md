# Duelo de Reflejos

PWA para dos jugadores online (Node + WebSocket). 5 rondas de minijuegos de habilidad:
Reflejo, Puntería, Toques rápidos y Memoria. Se juega con un código de sala de 4 letras.

- `npm install && npm start` → http://localhost:3000
- `npm test` → partida completa con dos clientes simulados (incluye reconexión)
- Despliegue: Render (`render.yaml`), health check en `/healthz`
